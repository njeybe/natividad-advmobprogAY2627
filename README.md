## 📱 Laboratory Activity 1: Flutter State Management Fundamentals

### 🎯 Goal
Understand the core differences between local (ephemeral) UI state and global (application-wide) state management in Flutter.

### ✨ Key Highlights
* **Interactive Counter Screen:** Demonstrates local state (`setState`) to manage temporary, screen-level count interactions.
* **Global Theme Switching:** Utilizes app-wide state management (`Provider`) to seamlessly toggle between Light and Dark themes across all screens.
* **Multi-Screen Flow:** Implements smooth screen transitions connecting the counter interface to the theme settings page.

---

## 🛍️ Laboratory Activity 2: Product Discovery & Interactive UI

### 🎯 Goal
Transform basic product listings into a visually engaging, responsive e-commerce storefront with intuitive discovery and filtering tools.

### ✨ Key Highlights
* **Modern 2-Column Product Grid:** Responsive card layout featuring product images, gold rating badges, and promotional discount tags.
* **Real-Time Search & Category Filters:** Live keyword searching with interactive category chips for instant product filtering.
* **Interactive Product Detail Screen:** Fluid Hero animations, a wishlist heart toggle, stock availability badges, and shipping/warranty policy highlights.
* **Integrated Theme Controls:** Dedicated settings switcher for instantaneous Light and Dark mode transitions.

---

## 🛒 Laboratory Activity 3: Shopping Cart & E-Commerce Flow

### 🎯 Goal
Bridge product discovery with purchasing capabilities by building an itemized shopping cart and seamless product inspection workflow.

### ✨ Key Highlights
* **Dynamic Shopping Cart View:** Real-time itemized cart displaying product images, quantity adjusters (`+` / `-`), and live order price calculations.
* **Seamless Product Flow:** Tap directly on any cart item to return to its rich product detail view for quick inspection.
* **Centralized Commerce Services:** Organized service layer to fetch, manage, and calculate shopping cart items efficiently.
* **Adaptive Visual Theme:** Cohesive cart UI styling that responds dynamically to Light and Dark mode preferences.

---

## 👤 Laboratory Activity 4: User Authentication & Personalization

### 🎯 Goal
Introduce secure user authentication and session management to deliver a personalized, user-specific e-commerce experience.

### ✨ Key Highlights
* **Animated Splash Screen:** Engaging branded startup animation with an automatic session check that routes users to the correct screen.
* **Persistent User Sign-In:** Secure login experience that remembers active sessions across app restarts using local device storage.
* **User Profile Dashboard:** Dedicated profile view displaying user credentials, account details, and safe sign-out functionality.
* **Personalized Cart Loading:** Dynamically fetches and renders the active user's specific cart items based on their unique authenticated profile.
